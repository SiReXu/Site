# Сайт-визитка Skyborn

Статичный сайт: HTML + CSS + JS. Сервер, установка и регистрация не нужны.

## Как открыть
Дважды щёлкните по `index.html` (или в VS Code: расширение Live Server → Go Live).

## Что поменять под себя
Откройте `js/config.js` — там состав семьи (`members`).

Форма заявки (`join.html`) только показывает сообщение «Заявка отправлена»: данные никуда не передаются и нигде не сохраняются.

Тексты на страницах правятся прямо в `.html` файлах, цвета — в начале `css/style.css`.
Картинку-фон замените файлом `img/hero.svg` (или поправьте путь в HTML).

## GitHub Pages
1. Создайте репозиторий и загрузите в него ВСЕ эти файлы (чтобы `index.html` лежал в корне).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
